Summary

Selected

Use “Move / select” and click a vertex. Click a second one to find the shortest path.

Vertex and edge

A graph G = (V, E) is a set of vertices joined by edges. Each edge connects two vertices (its endpoints).

Degree

The degree of a vertex is the number of edge ends touching it (a loop counts twice). Handshaking lemma: the degrees add up to 2|E|.

Adjacency

Two vertices are adjacent when an edge joins them. The adjacency matrix has entry 1 (or more) where they are adjacent.

Loops, multiple edges, simple graphs

A loop joins a vertex to itself. Parallel edges share both endpoints. A graph with neither is simple.

Path, connectivity, components

A path is a walk with no repeated vertices. A graph is connected if a path links every pair of vertices. Select two vertices to see a shortest path.

Cycle, tree, bipartite

A cycle is a closed path. A tree is a connected graph with no cycle. A bipartite graph can be coloured with two colours so no edge joins equal colours.

Complete graph and Euler trail

Kn has an edge between every pair. A connected graph has an Euler circuit if every degree is even, and an Euler trail if exactly two are odd.
